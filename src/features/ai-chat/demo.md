### 2. 消息流程

#### 用户发送消息
```
用户输入 → 点击发送/按Enter → 显示用户消息 → 调用API → 显示AI回复
```

#### 消息显示样式

**用户消息（右侧）：**
```
                                    [用户消息内容]  👤
                                         19:20
```

**AI消息（左侧）：**
```
🤖  [AI回复内容]
    19:20
```

### 3. 交互演示

#### 场景1：发送第一条消息
```
用户: "你好"
AI: "抱歉，我无法回答与编程无关的问题。如果你有关于前端开发的问题，欢迎随时提问！"
```

#### 场景2：创建新对话
```
点击 [+ 新增对话] → 创建新对话 → 清空消息列表 → 开始新的对话
```

#### 场景3：切换历史对话
```
点击历史对话项 → 加载对话消息 → 显示历史消息
```

#### 场景4：管理对话
```
点击对话菜单(⋯) → 选择操作：
  1. 重命名 → 输入新标题 → 更新对话标题
  2. 删除 → 确认删除 → 删除对话
```

### 4. 键盘快捷键

- `Enter` - 发送消息
- `Shift + Enter` - 换行
- `Esc` - 清空输入（计划中）
- `Ctrl + K` - 新建对话（计划中）

### 6. 响应式状态

#### 加载状态
```
isLoading = true  → 显示打字指示器
isLoading = false → 显示AI消息
```

#### 消息状态
```
发送中  → ⏳
已发送  → ✓
失败    → ✗ (重试)
```

### 7. 错误处理

#### API调用失败
```typescript
try {
  const response = await sendMessage(message);
  // 处理响应
} catch (error) {
  // 显示默认回复
  const fallbackMessage = {
    role: 'assistant',
    content: '抱歉，我无法回答与编程无关的问题...'
  };
}
```

#### 网络错误
```
显示提示：网络连接失败，请检查网络设置
提供重试按钮
```

### 8. 数据流转

```
用户输入
  ↓
添加到messages数组（乐观更新）
  ↓
调用API
  ↓
接收AI响应
  ↓
添加AI消息到messages数组
  ↓
更新聊天历史的lastMessage
  ↓
滚动到底部
```

```typescript
// Composable状态
```

## 使用步骤

### 第一步：访问页面
```
打开浏览器 → 访问 http://localhost:5173/aiChat
```

### 第二步：查看界面
- 左侧：侧边栏（功能列表和历史记录）
- 右侧：聊天主区域（消息显示和输入框）

### 第三步：开始聊天
1. 在输入框输入消息
2. 按Enter发送
3. 等待AI回复
4. 继续对话...

### 第四步：管理对话
- 点击"新增对话"创建新对话
- 点击历史记录切换对话
- 点击菜单管理对话（重命名/删除）
