# AI 聊天界面

这是一个仿照智汇云舟设计的AI聊天界面，具有完整的聊天功能和美观的UI设计。

## 功能特性

### 1. 侧边栏功能
- ✅ Logo和品牌标识
- ✅ 新增对话按钮
- ✅ 功能列表（AI搜索、帮我写作、AI编程、图像生成等）
- ✅ 历史对话列表
- ✅ 对话管理（重命名、删除）

### 2. 聊天主区域
- ✅ 消息气泡显示（用户消息/AI消息）
- ✅ 打字指示器
- ✅ 消息时间显示
- ✅ 自动滚动到最新消息
- ✅ 空状态提示

### 3. 输入区域
- ✅ 多行文本输入
- ✅ Enter发送、Shift+Enter换行
- ✅ 语音输入按钮
- ✅ 发送按钮状态管理

### 4. API集成
- ✅ 发送消息到AI
- ✅ 创建新对话
- ✅ 加载聊天历史
- ✅ 加载对话消息
- ✅ 删除对话
- ✅ 更新对话标题

## 使用方法

### 1. 访问聊天界面

在浏览器中访问：
```
http://localhost:5173/aiChat
```

### 2. 基本操作

#### 创建新对话
点击侧边栏顶部的"新增对话"按钮

#### 发送消息
- 在输入框中输入消息
- 按Enter键发送
- 按Shift+Enter换行

#### 切换对话
点击历史对话列表中的任意对话

#### 管理对话
点击对话右侧的三点菜单，可以重命名或删除对话

### 3. API配置

聊天功能使用以下API端点（需要在后端配置）：

```typescript
// 发送消息
POST /ai/chat
{
  message: string,
  chatId: string
}

// 创建新对话
POST /ai/chat/create
{
  title: string
}

// 获取聊天历史
GET /ai/chat/history

// 获取对话消息
GET /ai/chat/:chatId/messages

// 删除对话
DELETE /ai/chat/:chatId

// 更新对话标题
PUT /ai/chat/:chatId
{
  title: string
}
```

### 4. 自定义配置

#### 修改用户名
在 `AiChat.vue` 中修改：
```typescript
const userInitial = computed(() => '你的名字'.charAt(0));
```

在头部修改：
```html
<h1>晚上好，你的名字</h1>
```

#### 修改功能列表
在 `AiChat.vue` 的 `feature-list` 部分添加或修改功能项

#### 自定义样式
所有样式都在 `AiChat.vue` 的 `<style>` 标签中，可以根据需要调整颜色、字体、间距等

## 技术栈

- 打字指示器动画

### 响应式设计
- 侧边栏固定宽度：280px
- 主区域自适应宽度
- 消息最大宽度：60%
