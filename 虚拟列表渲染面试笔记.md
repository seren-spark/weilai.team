# 虚拟列表渲染 - 面试深挖笔记

## 一、核心概念

### 1.1 什么是虚拟列表？

虚拟列表是一种性能优化技术，只渲染可视区域内的列表项，而不是渲染全部数据。当用户滚动时，动态计算并更新需要渲染的元素。

### 1.2 为什么需要虚拟列表？

- **性能问题**：大量 DOM 节点会导致页面卡顿
- **内存占用**：每个 DOM 节点都占用内存
- **渲染时间**：初始渲染和重绘时间过长
- **用户体验**：滚动不流畅，交互延迟

### 1.3 适用场景

- 长列表（数千条以上数据）
- 聊天记录、评论列表
- 数据表格、日志查看器
- 社交媒体信息流

---

## 二、实现原理

### 2.1 基本原理

```
可视区域高度 = viewport height
列表总高度 = 数据总数 × 每项高度
可见项数量 = Math.ceil(可视区域高度 / 每项高度)
起始索引 = Math.floor(滚动距离 / 每项高度)
结束索引 = 起始索引 + 可见项数量 + 缓冲区
```

### 2.2 核心要素

1. **容器元素**：固定高度，可滚动
2. **占位元素**：撑开总高度，触发滚动条
3. **可视区域**：实际渲染的列表项
4. **偏移量**：通过 transform 定位可视区域

## 三、等高元素实现（最简单）

### 3.1 特点

- 每个列表项高度固定且相同
- 计算简单，性能最优
- 实现难度低

### 3.2 核心代码

```typescript
interface VirtualListProps {
  data: any[];
  itemHeight: number; // 固定高度
  containerHeight: number;
}

function useVirtualList(props: VirtualListProps) {
  const scrollTop = ref(0);

  // 计算可见范围
  const visibleCount = computed(() =>
    Math.ceil(props.containerHeight / props.itemHeight),
  );

  // 起始索引
  const startIndex = computed(() =>
    Math.floor(scrollTop.value / props.itemHeight),
  );

  // 结束索引（加缓冲区）
  const endIndex = computed(() =>
    Math.min(startIndex.value + visibleCount.value + 5, props.data.length),
  );

  // 可见数据
  const visibleData = computed(() =>
    props.data.slice(startIndex.value, endIndex.value),
  );

  // 偏移量
  const offsetY = computed(() => startIndex.value * props.itemHeight);

  // 总高度
  const totalHeight = computed(() => props.data.length * props.itemHeight);

  return {
    visibleData,
    offsetY,
    totalHeight,
    onScroll: (e: Event) => {
      scrollTop.value = (e.target as HTMLElement).scrollTop;
    },
  };
}
```

### 3.3 模板结构

```vue
<template>
  <div
    class="virtual-list-container"
    :style="{ height: containerHeight + 'px' }"
    @scroll="onScroll"
  >

    </div>
  </div>
</template>
```

## 四、不等高元素实现（预知高度）

### 4.1 特点

- 每个列表项高度不同，但提前知道
- 需要维护位置映射表
- 计算复杂度增加

### 4.2 核心思路

使用**位置缓存数组**记录每项的 top、bottom、height

```typescript
interface PositionCache {
  index: number;
  top: number;
  bottom: number;
  height: number;
}

function useVariableHeightList(data: any[], heights: number[]) {
  // 构建位置缓存
  const positions = ref<PositionCache[]>([]);

  function initPositions() {
    let top = 0;
    positions.value = heights.map((height, index) => {
      const item = {
        index,
        top,
        bottom: top + height,
        height,
      };
      top += height;
      return item;
    });
  }

  // 二分查找起始索引
  function getStartIndex(scrollTop: number): number {
    let left = 0;
    let right = positions.value.length - 1;

    while (left < right) {
      const mid = Math.floor((left + right) / 2);
      if (positions.value[mid].bottom < scrollTop) {
        left = mid + 1;
      } else {
        right = mid;
      }
    }

    return left;
  }

  // 获取可见数据
  function getVisibleData(scrollTop: number, containerHeight: number) {
    const start = getStartIndex(scrollTop);
    let end = start;
    let visibleHeight = 0;

    // 累加高度直到超出可视区域
    while (end < positions.value.length && visibleHeight < containerHeight) {
      visibleHeight += positions.value[end].height;
      end++;
    }

    return {
      startIndex: start,
      endIndex: Math.min(end + 5, data.length), // 加缓冲
      offsetY: positions.value[start]?.top || 0,
    };
  }

  return {
    initPositions,
    getVisibleData,
    totalHeight: computed(
      () => positions.value[positions.value.length - 1]?.bottom || 0,
    ),
  };
}
```

## 五、动态高度实现（最复杂）

### 5.1 特点

- 高度完全未知，需要渲染后测量
- 需要动态更新位置缓存
- 实现难度最高，但最灵活

### 5.2 核心策略

#### 策略一：预估高度 + 实际测量

```typescript
interface DynamicListItem {
  index: number;
  top: number;
  bottom: number;
  height: number;
  estimatedHeight: number; // 预估高度
  actualHeight?: number; // 实际高度
}

function useDynamicHeightList(data: any[], estimatedHeight: number = 50) {
  const positions = ref<DynamicListItem[]>([]);
  const itemRefs = ref<Map<number, HTMLElement>>(new Map());

  // 初始化：使用预估高度
  function initPositions() {
    let top = 0;
    positions.value = data.map((_, index) => {
      const item = {
        index,
        top,
        bottom: top + estimatedHeight,
        height: estimatedHeight,
        estimatedHeight,
      };
      top += estimatedHeight;
      return item;
    });
  }

  // 更新实际高度
  function updateItemHeight(index: number, actualHeight: number) {
    const item = positions.value[index];
    if (!item || item.actualHeight === actualHeight) return;

    const diff = actualHeight - item.height;
    item.height = actualHeight;
    item.actualHeight = actualHeight;
    item.bottom = item.top + actualHeight;

    // 更新后续所有项的位置
    for (let i = index + 1; i < positions.value.length; i++) {
      positions.value[i].top += diff;
      positions.value[i].bottom += diff;
    }
  }

  // 测量已渲染元素的高度
  function measureRenderedItems() {
    itemRefs.value.forEach((el, index) => {
      const height = el.getBoundingClientRect().height;
      updateItemHeight(index, height);
    });
  }

  // 在 onMounted 和 onUpdated 中调用
  onMounted(measureRenderedItems);
  onUpdated(measureRenderedItems);

  return {
    positions,
    itemRefs,
    initPositions,
    updateItemHeight,
  };
}
```

#### 策略二：ResizeObserver 监听

```typescript
function useResizeObserver() {
  const observer = ref<ResizeObserver>();

  function observeItem(el: HTMLElement, index: number) {
    if (!observer.value) {
      observer.value = new ResizeObserver((entries) => {
        entries.forEach((entry) => {
          const index = Number(entry.target.getAttribute("data-index"));
          const height = entry.contentRect.height;
          updateItemHeight(index, height);
        });
      });
    }

    observer.value.observe(el);
  }

  onUnmounted(() => {
    observer.value?.disconnect();
  });

  return { observeItem };
}
```

### 5.3 完整实现示例

```vue
<script setup lang="ts">
import { ref, computed, onMounted, onUpdated } from "vue";

interface Message {
  id: string;
  content: string;
}

const props = defineProps<{
  messages: Message[];
  containerHeight: number;
  estimatedHeight?: number;
}>();

const scrollTop = ref(0);
const positions = ref<DynamicListItem[]>([]);
const itemRefs = new Map<number, HTMLElement>();

// 初始化位置
function initPositions() {
  const estimated = props.estimatedHeight || 80;
  let top = 0;

  positions.value = props.messages.map((_, index) => ({
    index,
    top,
    bottom: top + estimated,
    height: estimated,
    estimatedHeight: estimated,
  }));

  top += estimated;
}

// 更新高度
function updateHeight(index: number, height: number) {
  const item = positions.value[index];
  if (!item || item.actualHeight === height) return;

  const diff = height - item.height;
  item.height = height;
  item.actualHeight = height;
  item.bottom = item.top + height;

  // 批量更新后续位置
  for (let i = index + 1; i < positions.value.length; i++) {
    positions.value[i].top += diff;
    positions.value[i].bottom += diff;
  }
}

// 测量元素
function measureItems() {
  itemRefs.forEach((el, index) => {
    const rect = el.getBoundingClientRect();
    updateHeight(index, rect.height);
  });
}

// 二分查找
function binarySearch(scrollTop: number) {
  let left = 0,
    right = positions.value.length - 1;

  while (left < right) {
    const mid = Math.floor((left + right) / 2);
    if (positions.value[mid].bottom < scrollTop) {
      left = mid + 1;
    } else {
      right = mid;
    }
  }

  return left;
}

// 计算可见数据
const visibleData = computed(() => {
  const start = binarySearch(scrollTop.value);
  let end = start;
  let height = 0;

  while (end < positions.value.length && height < props.containerHeight + 200) {
    height += positions.value[end].height;
    end++;
  }

  return {
    list: props.messages.slice(start, end),
    startIndex: start,
    offsetY: positions.value[start]?.top || 0,
  };
});

const totalHeight = computed(
  () => positions.value[positions.value.length - 1]?.bottom || 0,
);

onMounted(() => {
  initPositions();
  measureItems();
});

onUpdated(() => {
  measureItems();
});

function setItemRef(el: any, index: number) {
  if (el) {
    itemRefs.set(index, el);
  }
}
</script>

<template>
  <div
    class="virtual-container"
    :style="{ height: containerHeight + 'px' }"
    @scroll="scrollTop = ($event.target as HTMLElement).scrollTop"
  >
    <div :style="{ height: totalHeight + 'px' }" />

    <div :style="{ transform: `translateY(${visibleData.offsetY}px)` }">
      <div
        v-for="(item, idx) in visibleData.list"
        :key="item.id"
        :ref="(el) => setItemRef(el, visibleData.startIndex + idx)"
        :data-index="visibleData.startIndex + idx"
      >
        {{ item.content }}
      </div>
    </div>
  </div>
</template>
```

## 七、常见问题与解决方案

### 7.1 滚动抖动

**原因**：高度计算不准确导致位置跳动

**解决**：

- 使用更准确的预估高度
- 增加缓冲区大小
- 使用 `will-change: transform` 优化渲染

### 7.2 快速滚动白屏

**原因**：渲染速度跟不上滚动速度

**解决**：

- 增大缓冲区
- 使用骨架屏占位
- 降低滚动灵敏度

### 7.3 内存泄漏

**原因**：事件监听器、定时器未清理

**解决**：

```typescript
onUnmounted(() => {
  observer.value?.disconnect();
  if (rafId) cancelAnimationFrame(rafId);
  itemRefs.clear();
});
```

### 7.4 滚动位置丢失

**原因**：数据更新后位置重置

**解决**：

```typescript
// 保存滚动位置
const savedScrollTop = scrollTop.value;

// 更新数据
updateData(newData);

// 恢复滚动位置
nextTick(() => {
  containerRef.value.scrollTop = savedScrollTop;
});
```

## 八、面试高频问题

### Q1: 虚拟列表和分页加载有什么区别？

**答**：

- **虚拟列表**：所有数据在内存中，只渲染可见部分，适合已知总数的场景
- **分页加载**：按需加载数据，适合数据量未知或超大的场景
- 可以结合使用：虚拟列表 + 无限滚动

### Q2: 如何处理列表项中的图片加载？

**答**：

1. 使用懒加载，只加载可见区域的图片
2. 图片加载完成后重新测量高度
3. 使用占位图保持布局稳定
4. 考虑使用 IntersectionObserver

### Q3: 虚拟列表如何支持双向滚动（表格）？

**答**：

- 同时虚拟化行和列
- 维护二维位置缓存
- 计算可见行列范围
- 使用 `transform` 同时控制 X 和 Y 偏移

### Q4: 如何优化首屏渲染？

**答**：

1. 只渲染首屏可见项
2. 使用 `v-once` 优化静态内容
3. 延迟渲染复杂组件
4. 使用 Web Worker 处理数据

### Q5: 动态高度列表如何实现平滑滚动到指定项？

**答**：

```typescript
function scrollToIndex(index: number) {
  const position = positions.value[index];
  if (!position) return;

  containerRef.value?.scrollTo({
    top: position.top,
    behavior: "smooth",
  });
}
```
